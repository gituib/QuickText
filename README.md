# QuickText 文本自动输入器

一个 Windows 桌面小工具：把常用的文字预先存成「短语」，之后在**任意**输入框里按一下全局快捷键，程序就把这段文字打进当前焦点窗口。

适合反复输入同样内容的场景——客服话术、邮箱地址、收件信息、代码片段、表单模板、带日期的落款。除了"一键输入"，它还带一个快捷选择器（在光标旁弹出列表直接挑）、一个常驻的速填面板，以及一个应用速启器。

- 语言 / 界面：简体中文
- 平台：Windows 10 / 11（x64），无需管理员权限即可安装与运行
- 技术栈：Python 3.13 + PySide6（Qt Widgets）
- 当前版本：v0.1.0
- 联网：**完全不联网**，不收集任何数据（详见[隐私说明](file:///d:/软件开发/楼月/隐私说明.md)）

## 核心功能

| 功能 | 说明 |
|---|---|
| **全局热键输入** | 每条短语可绑定一个自己的快捷键（如 `Ctrl+Alt+1`），在任意窗口按下即输出内容 |
| **快捷选择器** | 按一个热键在光标附近弹出短语列表，边打字边过滤，回车插入 |
| **速填悬浮面板** | 常驻屏幕边缘的置顶小面板，点一下就输入，不用切窗口 |
| **分组管理** | 按项目/场景分组，侧栏切换，支持新建、重命名、删除、拖拽排序、批量移动 |
| **模糊检索** | 按名称、缩写、分组、快捷键、正文匹配，还支持**拼音首字母**（输入 `kfsq` 能搜到「开发票申请」） |
| **变量与宏** | 正文里可写 `{date}`、`{clipboard}`、`{wait:500}`、`{key:Tab}` 等占位符 |
| **应用速启** | 索引开始菜单与桌面，一个热键搜开任意本机程序 |
| **内容遮挡** | 默认把短语正文显示为 `••••`，防止旁人窥屏，不影响搜索与输出 |
| **本地加密存储** | 数据文件用 Windows DPAPI 加密，与当前 Windows 账户绑定 |
| **托盘常驻** | 关窗口不退出，托盘菜单可切换面板、暂停热键、退出 |
| **导入 / 导出** | JSON 备份跨机器迁移（导出为明文，导入自动跳过重复） |
| **明暗主题** | 三套界面主题：经典、浅色 · 湖青（默认）、深色 |

## 下载与安装

### 方式一：使用安装包（推荐）

从仓库的 **Releases** 页面下载 `QuickText_setup_<版本号>.exe`（例如 `QuickText_setup_0.1.0.exe`），双击安装。

- 默认安装到 `%LOCALAPPDATA%\Programs\QuickText`，**只装给当前用户，不需要管理员权限**
- 安装完成可勾选立即启动；是否创建桌面图标由你选
- 程序启动后常驻**系统托盘**，不会在任务栏留一个窗口

### 方式二：绿色版单文件

不想装安装包，可以直接使用 PyInstaller 产出的单文件 `QuickText.exe`（在 Actions 构建产物中，或按[本地打 exe](#本地打-exe)自行构建）。免安装、双击即用，数据写在该 exe 同级的 `data` 子目录里，整个文件夹拷走就是完整迁移。

### 卸载

控制面板 → 「QuickText 文本自动输入器」→ 卸载。

卸载程序会先结束正在运行的进程，然后弹出一个带勾选框的对话框，列出它找到的数据目录：

- **不勾选（默认）**：只删程序文件，保留你的全部短语和设置，日后重装直接可用
- **勾选**：永久删除数据目录，不可恢复；想留一份请先在程序里「导出」

静默卸载（`/SILENT`）一律保留数据、不弹框。

## 快速上手

1. 启动 QuickText，托盘出现图标。双击托盘图标打开主窗口。
2. 点左上角「**+ 新建短语**」。
3. 填「内容」（必填，这段文字就是会被输入的内容）；「名称」可留空，但建议写上方便检索；想绑定快捷键就在「快捷键」框里**直接按下组合键**。
4. 保存后回到你原来干活的窗口，按那组快捷键——文字就出现了。

不想给每条短语单独设键，就用**快捷选择器**：在任何地方按 `Ctrl+R`，输入几个字过滤，回车插入。这是多数人日常最省事的用法。

第一次使用建议顺手做两件事：在设置里确认「开机自启」，以及试用一下正文里的 `{date}` 这类占位符。

## 界面说明

### 主窗口

- **左侧栏**：分组列表，固定有「全部短语」「未分组」两项，下面是你自己的分组。分组支持右键菜单（新建/重命名/删除/显示全部）和拖拽调整顺序。
- **顶栏**：「+ 新建短语」、搜索框、`隐藏内容 ⇄ 显示内容` 切换按钮、`•••` 更多菜单。
- **列表**：四列 —— 名称 / 分组 / 快捷键 / 内容。支持鼠标多选，列宽可拖动并会被记住。
- **列表右键菜单**：修改、复制内容、启用所选、停用所选、移动到分组、删除所选。
- **状态栏**：显示"就绪"以及"共 N 条 · 启用 N"。

主窗口右上角的关闭按钮只是**隐藏**到托盘，程序仍在后台运行、热键仍然有效。要真正退出请用托盘菜单的「退出」。

### 快捷选择器

按 `Ctrl+R` 在**鼠标光标 / 输入点附近**弹出（460×440），顶部是搜索框，提示语为 `Enter 插入 · Esc 关闭`。

- 输入即可过滤，命中名称、缩写、分组、拼音首字母或正文
- `↑` `↓` 移动，回车把选中短语插入到唤起前的那个窗口
- 默认「最近使用的排在前面」，可在设置里关掉
- 鼠标点一行同样能插入；点击外部区域自动关闭

### 速填悬浮面板

常驻屏幕边缘的置顶小窗，适合一整天都开着。

- 默认 320×420；宽度 240–520、高度 200–800 可调，边缘可拖拽缩放
- 不透明度 30–100%（默认 97）
- 每条显示 1–5 行（默认 2 行）
- 可吸附到屏幕左或右边缘（默认左，距边 12px）
- 「复制」「输入」两个按钮可分别显示或隐藏
- 面板内有暂停热键按钮、`显示/隐藏内容` 按钮和齿轮「面板设置」入口
- 位置与大小会记住；面板开关状态同样会被记住

### 应用速启

按 `Ctrl+Alt+Space` 弹出一个搜索框（600×460），输入名称、拼音首字母或别名，回车启动。

- 索引范围：当前用户与公共的**开始菜单 → 程序**、**桌面**，只收 `.lnk` 和 `.exe`
- 同名去重优先级：用户开始菜单 > 公共开始菜单 > 桌面；快捷方式优先于裸 exe
- `↑` `↓` / `PageUp` `PageDown` 选择，回车打开，`Esc` 关闭，右键可置顶、设置别名、从列表隐藏
- 结果最多显示 60 条
- 默认会过滤掉「卸载 xxx」「帮助」「更新」「repair」这类噪音项，可在设置里放开
- 缓存文件为 `apps.json`；可在设置里手动「重建索引」或管理已隐藏的应用

### 输入方式

程序"替你打字"有三条路，可在设置里选：

| 模式 | 行为 |
|---|---|
| **逐字输入** | `SendInput` 模拟 Unicode 按键，逐字符输出，最兼容但长文本慢 |
| **剪贴板粘贴** | 备份原剪贴板 → 写入短语 → 模拟 `Ctrl+V` → 等待 300ms → 还原剪贴板 |
| **自动**（默认） | 正文 ≤ 400 字符走逐字，超过则用粘贴；若剪贴板里是图片/文件等富内容，退回逐字以免覆盖 |

粘贴失败时会自动降级为逐字输入，不会丢内容。

## 短语内容：变量与宏

短语正文里写 `{...}`，触发时会被实时解析。识别不了的 `{xxx}` 原样输出，所以正常文字里出现花括号不必担心。

### 变量（输出文本）

| 写法 | 输出示例 |
|---|---|
| `{date}` | `2026-11-25` |
| `{date:%Y年%m月%d日}` | `2026年11月25日`（任意 `strftime` 格式） |
| `{time}` | `14:30:05` |
| `{datetime}` | `2026-11-25 14:30:05` |
| `{year}` `{month}` `{day}` | `2026` `11` `25` |
| `{hour}` `{minute}` `{second}` | `14` `30` `05` |
| `{clipboard}` | 当前剪贴板里的文本 |
| `{uuid}` | 一个随机 UUID（32 位十六进制） |

### 宏（执行动作，不输出文字）

| 写法 | 作用 |
|---|---|
| `{wait:500}` | 等待 500 毫秒（写小数按秒，如 `{wait:1.5}`）；上限 60000ms |
| `{key:Enter}` | 按下按键 |
| `{key:Ctrl+V}` | 按下组合键 |
| `{ctrl+enter}` | 同上，直接写组合键 |

可用键名：`enter` `tab` `esc` `space` `backspace` `delete` `insert` `home` `end` `pageup` `pagedown` `left` `up` `right` `down` `f1`–`f12`，以及任意单个字母/数字。修饰键：`ctrl` `alt` `shift` `win`。

### 转义

`{{` 输出一个 `{`，`}}` 输出一个 `}`。

### 组合示例

```
您好，{clipboard} 的订单（单号 {uuid}）已于 {date} 发出，
预计 3 日内送达。如有疑问请回复本邮件。{key:Enter}{wait:300}此致
```

触发时依次完成：粘贴剪贴板内容 → 换行 → 生成随机单号 → 填入今天日期 → 按一次回车 → 等 300ms → 输出结尾。

**限制**：单条正文最长 **100,000 字符**，超出会提示并拒绝输入。

## 设置项一览

主窗口 `•••` 菜单或 `Ctrl+O` 打开「选项」。

**常规**
- 开机自启（默认关）— 写入 `HKEY_CURRENT_USER\...\Run`，只影响当前账户
- 启动时最小化到托盘（默认关）

**外观**
- 主题：经典 / 浅色 · 湖青（默认）/ 深色
- 主窗口列表列宽会被记住

**输入**
- 输入方式：逐字输入 / 剪贴板粘贴 / 自动（默认「自动」）

**选择器**
- 打开选择器的热键（默认 `Ctrl+R`，必填）
- 最近使用的排在前面（默认开）

**主窗口**
- 显示 / 隐藏主窗口的热键（默认不设置）
- 隐藏内容：正文以 `••••` 遮挡显示（**默认开启**）

**速填面板**
- 是否显示面板（默认关，可走托盘菜单开启）
- 宽度 / 高度 / 不透明度 / 每条行数 / 是否吸附边缘 / 是否显示「复制」「输入」按钮
- 面板位置在关闭时被记住

**应用速启**
- 热键（默认 `Ctrl+Alt+Space`）
- 是否把卸载、帮助等系统项也编入索引（默认不编入）
- 「重建索引」「管理隐藏应用」按钮

## 数据存储与隐私

**一句话：数据只留在你自己的电脑上，程序不联网，也不记录你敲的按键。**

数据放在**安装目录下的 `data` 子目录**，方便随文件夹一起备份或整体搬移：

```
<安装目录>\data\              默认 %LOCALAPPDATA%\Programs\QuickText\data\
├── phrases.json       短语库 + 全部设置（DPAPI 加密）
├── phrases.json.bak   自动备份副本（主文件损坏时自动回退）
└── apps.json          应用速启的本机索引（明文）
```

- 如果该目录不可写（例如选了「为所有用户安装」，程序落在 `Program Files`），会自动退回 `%APPDATA%\QuickText\AutoTyper`
- 从旧版本升级后首次启动会把 `%APPDATA%` 下的同名文件**复制**过来，原件保留
- `phrases.json` 用 Windows **DPAPI** 加密，密钥由系统托管并绑定当前 Windows 账户，程序自身不存任何密钥。直接用记事本打开看不到内容
- 加密失败时降级写明文——**绝不因为加密问题丢数据或阻断保存**
- 换了 Windows 账户或密码被强制重置导致无法解密时，程序不会崩溃：把旧文件改名保留为 `phrases.json.unreadable-<时间戳>`，以空库启动并提示你，你可以用「导入」从明文备份恢复
- 「导出」生成的备份是**明文 JSON**（这样才跨机器可用），导出前会弹确认提示，请自行存放妥当
- 没有键盘钩子（源码中不存在 `SetWindowsHookEx`）、没有网络请求、没有运行日志

完整说明见 [隐私说明.md](file:///d:/软件开发/楼月/隐私说明.md)，其中也诚实列出了本程序**做不到**的几件事。

## 从源码运行

### 环境要求

- Windows 10 / 11 x64
- Python 3.13（3.11+ 应也可运行）

### 步骤

```powershell
pip install -r requirements.txt
python quicktext/main.py
```

`requirements.txt` 里只有 `PySide6==6.12.0` 是运行必需的；`pyinstaller` 仅打包时需要。

开发模式（未打包）下数据落在 `%APPDATA%\QuickText\AutoTyper`，因为程序无法确定"安装目录"。

### 非 Windows 环境

代码对 `win32` 做了分支保护，Linux/Mac 上可以启动界面用于开发调试，但全局热键、模拟输入、DPAPI 加密都依赖 Windows API，实际功能不可用。非 Windows 下数据退回明文存储。

## 打包与发布

### 本地打 exe

```powershell
pip install pyinstaller
pyinstaller --clean --noconfirm QuickText.spec
```

产物 `dist\QuickText.exe`（单文件、无控制台窗口）。[QuickText.spec](file:///d:/软件开发/楼月/QuickText.spec) 从 `quicktext/version.py` 读取版本号写入 exe 版本资源，并主动剔除用不到的 Qt 模块、平台插件与 200 多个翻译文件以压缩体积。

### 本地打安装包

需要安装 [Inno Setup 6](https://jrsoftware.org/isinfo.php)。

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" /DMyAppVersion=0.1.0 QuickText.iss
```

产物 `dist\QuickText_setup_0.1.0.exe`。不传 `/DMyAppVersion` 则使用脚本内默认值。

### 正式发布（CI 自动完成）

版本号只有一个来源：[quicktext/version.py](file:///d:/软件开发/楼月/quicktext/version.py)。发布就是打 tag：

```powershell
git tag v0.1.1
git push origin v0.1.1
```

GitHub Actions（[build.yml](file:///d:/软件开发/楼月/.github/workflows/build.yml)）会在 `windows-latest` 上依次：

1. 安装 Python 3.13 与依赖，`choco install innosetup`
2. 用 tag 名（去掉前缀 `v`，必须为 `x.y.z` 三段式）覆盖 `version.py`，确保 exe、安装包、Release 三处版本一致
3. PyInstaller 打 exe → 校验产物存在 → Inno Setup 打安装包
4. 上传 Actions 产物（保留 30 天）
5. tag 触发时自动发布 GitHub Release，附上安装包和自动生成的更新说明

在 Actions 页面**手动触发**（`workflow_dispatch`）则只构建、产物留在 Actions 里，不发 Release——适合验证改动是否可打包。

## 常见问题

**按快捷键没有反应？**
先看状态栏是否提示"部分快捷键注册失败"——多半是那组键被别的程序（微信、QQ、输入法、截图工具）抢占了。换一组键即可。也确认托盘菜单里没有勾上「暂停快捷键」。

**文字输到了错误的窗口 / 没输出？**
程序输出到**当前焦点窗口**。从选择器或悬浮面板触发时，它会自动把焦点还给唤起前的那个窗口；极少数情况下目标程序不接受焦点切换，可改用主窗口的「复制内容」再手动粘贴。

**内容里没有换行 / 换行变成了提交？**
部分聊天框按回车就发送。这时在正文里用 `{key:Shift+Enter}` 做软换行更稳妥。

**中文输入有乱码或丢字？**
切到「剪贴板粘贴」模式（设置 → 输入）。逐字模式依赖目标控件接受 Unicode 注入，个别自绘输入框不支持。

**换了电脑，短语怎么迁移？**
旧电脑「导出」成 JSON → 新电脑「导入」。注意导出文件是**明文**，传输过程自己保护好。DPAPI 加密的本机文件**不能**跨机器或跨账户使用。

**能防别人偷看我的短语吗？**
「隐藏内容」默认开启，界面上显示为 `••••`，能挡住偶然窥屏；数据文件本身也已加密。但它防不住同账户下运行的其它程序、远控或录屏——敏感操作请锁屏。

**想彻底删掉所有数据？**
卸载时勾选「删除上述数据目录」，或手动删除 `<安装目录>\data`（以及旧版遗留的 `%APPDATA%\QuickText\AutoTyper`）。

**程序会自启吗？**
不会自动。只有你在设置里勾选「开机自启」才会写入当前用户的 `Run` 项，取消勾选即移除，卸载时也会一并清掉。
